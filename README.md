# Fluid Package Manager
### Warning: This project is under development

The package manager from BeverageOS. Being a fundamental part of the project.
This version is the first of the project, and it's just an MVP.


## Usage

For list commands and usage:
```bash
    fluid
```

For installing packages:
```bash
    fluid install package_name
```

For removing packages:
```bash
    fluid remove package_name
```

For searching packages:
```bash
    fluid search package_name
```

## Mirrors
In the first time you execute fluid, it will create a basic mirrors file, which can be found at /etc/fluid/mirrors.
If you want to include your own mirror list (or server in the future), you just have to edit and add the url of the mirror.

## Installing Fluid
Just execute the `install.sh` file
